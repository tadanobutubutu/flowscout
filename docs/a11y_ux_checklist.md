# ♿ Flowscout UX & アクセシビリティ・チェックリスト

Flowscoutは、すべての開発者がいかなる環境でもストレスなく直感的に、かつ完全にアクセシブルに使用できる「ユーザーファースト極限アプリ」を目指します。本チェックリストは、WCAG 2.2、Apple HIG Accessibility、およびAndroid Build Accessible Appsに準拠しています。

---

## 🎨 1. ビジュアル ＆ カラーコントラスト

*   [ ] **ダークモード & ライトモードの完備:**
    *   デバイスのシステム設定に自動追従、かつアプリ内の「設定」から手動で自由にトグル切替できること。
*   [ ] **十分なコントラスト比の確保 (WCAG 2.2 AA準拠):**
    *   通常のテキストは **4.5:1** 以上のコントラスト比を確保する。
    *   大きなテキスト（18pt太字以上）は **3:1** 以上のコントラスト比を確保する。
*   [ ] **ハイコントラストモード (High Contrast Mode) の提供:**
    *   弱視のユーザーや、屋外の強い日光下でも文字がくっきりと視認できるよう、背景色と前景色を極限まで強調するオプションテーマを用意。
*   [ ] **色覚多様性（色盲・色弱）サポート:**
    *   「成功（緑）」「失敗（赤）」といったCI/CDのステータスを**色情報だけで表現しない**。必ずアイコン形状（✓、✗）やラベルテキスト（Success, Failure）を併用する。
    *   オプションとして、色盲に配慮したカラーパレット（例: 青とオレンジの組み合わせ）への切り替え機能を備える。

---

## 📱 2. レイアウト & 操作性 (UI/UX)

*   [ ] **タップターゲットの最小領域確保:**
    *   すべてのインタラクティブ要素（ボタン、リストカード、アイコン）は、誤タップを防ぐために最低 **`48 x 48 dp`** （iOSでは `44 x 44 pt`）以上の十分なタップ可能領域を確保する。
*   [ ] **テキストの拡大表示（フォントスケール）への追従:**
    *   OS側の文字サイズ変更機能に追従し、文字を大きくした際にレイアウトが崩れたり、文字が見切れて読めなくなったりしないようにレスポンシブに設計する。
*   [ ] **直感的な操作・レスポンス:**
    *   読み込み中には適切な進行状況インジケータ（CircularProgressIndicator）を表示し、非同期通信時にもユーザーを迷わせない。
    *   あらゆる操作エラー時には、技術的なエラーコードだけでなく「接続を再確認してください」といった親切な日本語/英語メッセージと再試行ボタンを提供する。

---

## 🗣️ 3. スクリーンリーダー対応 (TalkBack / VoiceOver)

*   [ ] **適切なセマンティクスラベリング:**
    *   すべてのカスタムアイコンやグラフィックボタンに対し、`Semantics` または `semanticsLabel` パラメータを使用して、具体的なアクションや意味をスクリーンリーダーに伝える。
*   [ ] **動的コンテンツの自動音声アナウンス (Live Regions):**
    *   非同期通信が完了して画面が切り替わった際、またはSnackBarなどの警告が表示された際に、`liveRegion: true` を用いて変更内容がスクリーンリーダーに即座に音声通知されるようにする。
*   [ ] **論理的なナビゲーション順序:**
    *   フォーカスが上から下、左から右へと自然な流れで移動するように実装し、キーボードやスイッチコントロールでの操作を妨げない。

---

## ⚡ 4. パフォーマンス ＆ 軽量動作 (ユーザー体験の向上)

*   [ ] **ミリ秒単位の応答性と快適性 (INP/LCP最適化):**
    *   初期読み込み時やリポジトリの切り替え時に、ガタつきのない滑らかなローディングスケルトンを導入し、ユーザーに待たされている感覚を与えない。
    *   不要なWidgetの再描画（Rebuild）を徹底的に抑え、スクロールや画面遷移のフレームレートを常時60fps/120fpsに維持する。
*   [ ] **リソースの最小化:**
    *   アプリのファイルサイズ（APK/IPA）を最小限に抑えるため、使用していないフォントやアセットを除外する。
    *   ネットワーク通信時のペイロードを最小化し、モバイルデータ通信量とバッテリー消費を保護する。

---

## 📴 5. オフラインファースト ＆ データキャッシュ

*   [ ] **オフラインでの閲覧機能:**
    *   一度取得したワークフローの履歴やログ情報をローカルDB（HiveやSharedPreferences等）に安全にキャッシュし、地下鉄の中や山間部などの電波の届かないオフライン環境でも直前のステータスを確認できるようにする。
*   [ ] **スマートな再試行とエラーハンドリング:**
    *   オフライン状態からオンラインに復帰した際、バックグラウンドで自動的に最新のステータスに同期（サイレントポーリング）する。
    *   オフライン時には分かりやすい「オフライン表示バナー」を画面上部に表示し、エラーポップアップでユーザーを煩わせない。

---

## 📳 6. ハプティクス ＆ インタラクティブ・フィードバック

*   [ ] **触覚フィードバック (Haptic Feedback) の効果的利用:**
    *   ビルドの「成功」や「失敗」の通知を受け取った際、または重要な操作（手動でのビルド実行、Token登録など）を完了した際に、端末のバイブレーション（心地よい微細な振動）を鳴らして五感でステータスを感じられるようにする。
*   [ ] **マイクロインタラクション:**
    *   ボタンを押したときの沈み込み、トグルスイッチの滑らかなスライド、ステータス変更時のふわっとしたアニメーションなど、触るのが「楽しい」と感じるインタラクションを徹底する。

---

## 🔒 7. セキュリティ ＆ プライバシー

*   [ ] **生体認証による安全なトークン保護:**
    *   アプリ起動時や機密情報（GitHub Tokenなど）へのアクセス時に、端末のFaceID/TouchIDまたは指紋認証/顔認証を要求するセキュリティロック機能を提供する。
*   [ ] **画面キャプチャ・覗き見防止オプション:**
    *   セキュリティレベルの高い環境で使用する開発者のため、アプリの履歴画面（タスクキラー）でアプリの中身をぼかす/隠す機能や、スクリーンショットの撮影を制限するプライバシーガードオプションを用意する。

---

## 🧭 8. スマートナビゲーション (親指ファースト)

*   [ ] **片手操作に最適化したレイアウト:**
    *   スマートフォンを片手で持った際に親指が届きやすい「画面下部」に、主要なアクションボタンやナビゲーションバーを集約する。
*   [ ] **ジェスチャーによる直感操作:**
    *   「左スワイプで前の画面に戻る」「下にスワイプでワークフローリストを更新（Pull to Refresh）」など、OS標準の快適なジェスチャーに完全追従する。
